# cars-2-toolkit

A Blender add-on to import, edit and export **Cars 2: The Video Game (Win32)** characters: models,
control rig, animation clips, FX markers, materials and textures.

## Install

1. Download **`cars2_toolkit.zip`** from the [Releases](../../releases/latest) page.
2. In Blender, go to **Edit > Preferences > Add-ons > Install from Disk**, pick the zip and enable **Cars 2 Toolkit**.
3. The tools are in **3D View > Sidebar (N) > Cars 2 Character**. 

Tested to work on Blender 5.2 LTS and later (also 5.x). Blender 4.1  support also.
